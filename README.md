# Jackpot Roofing & Gutters website

A static site ready for GitHub Pages. All site files live in the repository root; image assets live in `img/`.

## Add finished-roof photos from a phone

1. Open the repository on GitHub in your phone browser.
2. Open the `img` folder.
3. Choose **Add file → Upload files** and select the roof photos from your phone.
4. Commit the upload.

On a standard `github.io` GitHub Pages address, the website discovers the photos automatically. Each photo becomes a scrollable gallery card and can be opened full-screen. The company logo is intentionally excluded.

`update-gallery.js` remains available as an optional desktop fallback, but it is not needed for the mobile workflow.

## Publish with GitHub Pages

Push these files to the root of a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select the branch, and use the **/(root)** folder.
